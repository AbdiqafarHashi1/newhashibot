# Phase 1G-A MicroScalper 15m Scanner Signal-Mode Port (Superseded)

This report is retained only as historical context. Phase 1G-A's single-strategy MicroScalper-only scanner mode was superseded first by Phase 1G-B and then cleaned up by Phase 1G-C.

Current scanner signal-mode terminology is now only:

- `active_signal`
- `blocked_signal`

See `reports/backtests/phase-1g-c-active-signal-cleanup.md` for the current implementation and verification checklist.
