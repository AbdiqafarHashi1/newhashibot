# Phase 1F Full Strategy Calibration Lab

This report is generated by `scripts/backtest-optimizer.mjs`. It is research/backtest/calibration only and does not apply any live scanner, provider, Telegram, outcome, customer/Bot, execution, or DB `strategy_config` change. No trades are faked or forced.

## 1. Scope and Safety Confirmation
- Scope: calibrate crypto strategy families across fixture windows before any Phase 1G scanner port.
- Live scanner behavior was not changed by this calibration command.
- Provider logic, scanner schedule, Telegram send logic, outcome tracking, customer/package/Bot setup, broker/exchange/MT5/testnet execution, and DB `strategy_config` are out of scope.
- RR, distance guards, duplicate/one-active protections, and strategy identity gates remain audit subjects only.

- Crypto fixture path: `data/backtests/5m.csv`
- Full crypto CSV range: 2024-01-01T00:00:00.000Z -> 2025-09-06T15:10:00.000Z
- Strategies/timeframes tested: MicroScalper 5m, MicroScalper 15m, CompressionBreakout 15m, CompressionBreakout 1h, SwingContinuation 15m, SwingContinuation 1h
- Forex fixtures present: none

## 4. Pass/Fail Criteria
- Phase 1G candidate requires no negative scored windows unless explicitly justified, minimum PF ideally >= 1.15, positive average R, acceptable drawdown/loss streak, enough trades for timeframe, controlled expiry, no single-window dependency, and no fake/forced trades.
- MicroScalper expects high sample; 15m is prioritized if cleaner than 5m.
- CompressionBreakout accepts lower sample but must control fakeout/expiry and not depend on one window.
- SwingContinuation must be assessed separately on 15m and 1h, with current scanner-style 6h time-stop measured.
- Forex is not eligible for live port until real forex CSV fixtures validate pip-aware assumptions.

## 5. Parameter Search Space and Trade-Management Calibration
- Compared live-like, balanced, conservative, aggressive, and controlled search candidates.
- MicroScalper variations: `min_score`, `min_body_atr`, TP1/TP2 R, RSI thresholds, stop ATR multiplier, and max bars in trade to reduce 5m noise.
- CompressionBreakout variations: `min_score`, TP1/TP2 R, breakout buffer, box geometry, ATR expansion, stop ATR multiplier, and max bars in trade.
- SwingContinuation variations: `min_score`, TP1/TP2 R, pullback bars, RSI thresholds, stop ATR multiplier, and max-bars time stops including scanner-style 6h equivalents (`24` bars on 15m and `6` bars on 1h).
- Break-even/trailing assumptions were not invented; only parameters modeled by the existing fixture harness were varied.

## 6. Scanner vs Backtest Mismatch Findings
- MicroScalper: backtest defaults use balanced 5m/15m settings with `min_score=72`, `stop_atr_mult=1.4`, `tp1_r=1.2`, `tp2_r=1.8`; scanner fallback/default config can use `min_score=75`, evaluator fallback `stop_atr_mult=1.2`, `tp1_r=0.9`, `tp2_r=1.5`, plus `crypto_behavior_tuning=1`, arbitration, and duplicate-active-symbol locks. This explains why backtest MicroScalper can trade while scanner MicroScalper appears dead or suppressed.
- CompressionBreakout: backtest/research balanced candidate is aligned in broad concept, but scanner may still be using DB/fallback config rather than optimizer candidates; no Phase 1E/1F candidate is ported automatically.
- SwingContinuation: scanner runs it beside MicroScalper and CompressionBreakout on each crypto symbol/timeframe, then identity-weighted arbitration can favor SwingContinuation when it has clean trend/pullback fit. Backtest evaluates isolated strategy/timeframe trades without live duplicate locks.
- Duplicate/one-active-symbol locks: fixture backtest only blocks overlapping trades inside one strategy stream; scanner blocks new signals for a symbol when an active signal already exists and can mark the selected winner as duplicate blocked. This can hide MicroScalper when slower SwingContinuation already has an active symbol signal.
- Six-hour expiry: scanner-side signal expiry is independent from this harness, while harness `max_bars_in_trade` models strategy time-stop. The calibration explicitly compares 24 bars on 15m and 6 bars on 1h as scanner-style 6h limits.
- ForexMicroScalper/ForexSwingContinuation: scanner has real-provider evaluators and diagnostics, but no local forex CSV fixture exists in this repository, so forex is not calibrated or approved.
