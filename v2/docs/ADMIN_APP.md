# ADMIN_APP

The V2 admin shell is implemented in `/v2/apps/web-admin`.

## Pages created
Admin dashboard, customers, approvals, executors, signals, strategies, Telegram Manager, Affiliate Manager, billing/subscriptions, runtime, monitoring, protection center, recovery center, reports, audit logs, feature flags, and system settings.

## Data strategy
Admin pages use mock approvals, runtime health, protection states, executors, and Telegram channels. V1 raw operational tables are not read.
