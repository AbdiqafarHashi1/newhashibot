# Google Cloud / Supabase boundary

Supabase remains authoritative for Auth, PostgreSQL, configuration, customers, policies, signal truth, Trade Truth, audit, reporting, and Operations Center data. Google consumes approved reads and may write only existing shadow/audit evidence boundaries. If an evidence mapping is absent, the adapter returns a capability gap; it must not create a second store or write active Trade Truth. This phase changes no Edge Function, schedule, schema, or production ownership.
