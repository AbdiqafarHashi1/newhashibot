# Work period 7: existing admin controls, selection and reporting

Implemented inside the existing Providers & accounts / account strategy panel. No public/customer redesign, live activation, new tables or worker replacement.

- Gold Turbo controls appear only for MT5 Personal demo accounts. The authority endpoint independently verifies the signed-in Admin and exact customer/account ownership. Customer mutations, live, Prop and Crypto assignments are rejected.
- Selection supports one strategy, custom independent combinations and all five adaptively. Adaptive ranking uses planned net reward/risk and rejects close opposing choices; it is a heuristic awaiting historical comparison, not a proven improvement. Flagship source-opportunity attribution also prevents admitting the same underlying opportunity twice through the wrapper and standalone engine.
- Admin can configure decision/basket risk, daily/peak/open-risk limits, margin, basket target, session locks, and explicit commission/slippage reserves. Existing permission/lease bounds remain binding. Opposite hedges and netting remain blocked pending provider qualification.
- Saving preserves all other policy fields, records a durable REQUESTED audit intent and uses a compare-and-set write to avoid overwriting concurrent changes. Audit failure prevents mutation. Entries move to PAUSE without switching off existing-position management. Saving does not start trading; existing access, bridge flag and account Start checks still apply.
- Status travels through the existing heartbeat, without ticks or per-decision Supabase writes. It includes account-scoped observation time, lease/lock state, tracked realized/floating net values, committed basket risk, margin, active baskets and recent decisions. Server reads scope the connected account and sanitize/bound the projection. Missing status is unavailable; observations older than 30 seconds are labelled stale. UI refresh is manual.
- Exports include status JSON and recent-decision CSV. A local agent JSONL segment can be converted to CSV in-browser, without uploading it. Exports escape spreadsheet formulas/quotes and ignore unknown fields. Heartbeat projections contain at most 20 decisions/baskets; full logs retain audit events. Unchanged strategy decisions are recorded on state change or at five-second intervals, explicitly labelled as sampled observations.

Verification: 169 targeted Python tests (including three new adaptive/status tests), 12 shared lease/admin JavaScript tests, changed Edge Function/shared-module syntax checks, Python compilation, and targeted esbuild bundles for both account control components passed. Admin tests include customer denial, concurrent edits, failed audit, preserving other strategies, selection modes, stale/scoped status and CSV safety. No full-repository suite, hosted browser session or actual database/provider handshake was exercised.

Configuration is stored in the existing policy_overrides.gold_turbo JSON field. Deploy the changed existing phase-h-authority and mt5-bridge functions and updated agent during authorized activation; no migration is required. No account configuration was changed by this work.
